# `logo.svg` provenance

- Source: `docs/public/favicon.svg` in [mermaid-js/mermaid](https://github.com/mermaid-js/mermaid), pinned to commit
  [`b7d24c8325b189acac8a46875b7fe84e836be7b6`](https://github.com/mermaid-js/mermaid/blob/b7d24c8325b189acac8a46875b7fe84e836be7b6/docs/public/favicon.svg)
  (the latest commit touching that file as of 2026-09-26).
  `docs/public/mermaid-logo.svg` was also considered but is a white-only mark meant for dark
  backgrounds; `favicon.svg` carries the full-color pink rounded-square mark and is a truer
